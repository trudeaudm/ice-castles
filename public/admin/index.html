Trails

A trail is a set of markers. Each stop can use a different activation — QR scan, acknowledge, code entry, multiple choice, or a short reflection. The reward unlocks when every stop is complete.

Printable signs

Every marker has its own code. The QR points at /s/CODE, so a guest can scan it with their phone's normal camera and land straight in the app — no install step. Reprinting a sign? Roll the code first so the old printout stops working.
